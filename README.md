# Backend Learning Curve

This workspace contains small TypeScript backend experiments and a multi-service capstone project.

## Folders

- [`capstone`](capstone/README.md) - Docker Compose application with a PostgreSQL database, task service, and audit service.
- [`node_bun`](node_bun/README.md) - Fastify, Hono, Zod, and TypeBox examples running with TypeScript.

## Prerequisites

- Node.js 20 or newer
- pnpm 10 or newer
- Bun, if running the audit service directly
- Docker Desktop, if running the capstone stack

Each folder has its own README with setup and run instructions.
